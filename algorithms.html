01 / Library

题解与模板

按问题、核心思路、复杂度和实现组织，便于对照约束选择解法。

时间 O(n) · 空间 O(n)

两数之和

一次遍历数组，用哈希表保存已经访问过的数值与下标；当前值的补数若已出现即可返回答案。

查看 C++ 实现
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> seen;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            int need = target - nums[i];
            if (seen.count(need)) return {seen[need], i};
            seen[nums[i]] = i;
        }
        return {};
    }
};
时间 O(n) · 空间 O(字符集)

无重复字符的最长子串

滑动窗口维护当前无重复区间，右指针只前进一次，左指针移动时移除离开窗口的字符。

查看 C++ 实现
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_set<char> window;
        int right = -1;
        int answer = 0;
        for (int left = 0; left < static_cast<int>(s.size()); ++left) {
            if (left > 0) window.erase(s[left - 1]);
            while (right + 1 < static_cast<int>(s.size()) &&
                   !window.count(s[right + 1])) {
                window.insert(s[++right]);
            }
            answer = max(answer, right - left + 1);
        }
        return answer;
    }
};
时间 O(n log n) · 空间 O(n)

合并区间

先按左端点排序，再将新区间与结果末尾比较：不重叠则追加，重叠则更新右端点。

查看 C++ 实现
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> merged;
        for (const auto& interval : intervals) {
            if (merged.empty() || merged.back()[1] < interval[0]) {
                merged.push_back(interval);
            } else {
                merged.back()[1] = max(merged.back()[1], interval[1]);
            }
        }
        return merged;
    }
};
时间 O(log(m+n)) · 空间 O(1)

两个正序数组的中位数

将求中位数转换为求第 k 小元素，每轮排除一个数组中不可能成为答案的一段前缀。

查看 C++ 实现
class Solution {
public:
    int getKthElement(const vector<int>& a, const vector<int>& b, int k) {
        int i = 0, j = 0;
        while (true) {
            if (i == static_cast<int>(a.size())) return b[j + k - 1];
            if (j == static_cast<int>(b.size())) return a[i + k - 1];
            if (k == 1) return min(a[i], b[j]);

            int nextI = min(i + k / 2 - 1, static_cast<int>(a.size()) - 1);
            int nextJ = min(j + k / 2 - 1, static_cast<int>(b.size()) - 1);
            if (a[nextI] <= b[nextJ]) {
                k -= nextI - i + 1;
                i = nextI + 1;
            } else {
                k -= nextJ - j + 1;
                j = nextJ + 1;
            }
        }
    }

    double findMedianSortedArrays(vector<int>& a, vector<int>& b) {
        int total = static_cast<int>(a.size() + b.size());
        if (total % 2 == 1) return getKthElement(a, b, (total + 1) / 2);
        return (getKthElement(a, b, total / 2) +
                getKthElement(a, b, total / 2 + 1)) / 2.0;
    }
};
时间 O(log n) · 空间 O(1)

二分查找

在升序数组中查找目标值；用 left <= right 表示闭区间搜索范围。

查看 C++ 实现
int binarySearch(const vector<int>& values, int target) {
    int left = 0;
    int right = static_cast<int>(values.size()) - 1;
    while (left <= right) {
        int middle = left + (right - left) / 2;
        if (values[middle] == target) return middle;
        if (values[middle] < target) left = middle + 1;
        else right = middle - 1;
    }
    return -1;
}
时间 O(n log n) · 空间 O(n)

最长上升子序列

维护不同长度上升子序列的最小末尾值，并用二分查找替换位置。

查看 C++ 实现
int longestIncreasingSubsequence(const vector<int>& nums) {
    vector<int> tails;
    for (int value : nums) {
        auto position = lower_bound(tails.begin(), tails.end(), value);
        if (position == tails.end()) tails.push_back(value);
        else *position = value;
    }
    return static_cast<int>(tails.size());
}
时间 O((V + E) log V) · 空间 O(V + E)

Dijkstra 最短路径

使用邻接表和优先队列，每次扩展当前距离最小的节点；仅适用于非负边权。

查看 C++ 实现
using Edge = pair<int, int>;  // {next, weight}

vector<long long> dijkstra(
    int nodeCount,
    int source,
    const vector<vector<Edge>>& graph
) {
    const long long infinity = numeric_limits<long long>::max() / 4;
    vector<long long> distance(nodeCount, infinity);
    priority_queue<
        pair<long long, int>,
        vector<pair<long long, int>>,
        greater<pair<long long, int>>
    > queue;

    distance[source] = 0;
    queue.push({0, source});

    while (!queue.empty()) {
        auto [currentDistance, node] = queue.top();
        queue.pop();
        if (currentDistance != distance[node]) continue;

        for (const auto& [next, weight] : graph[node]) {
            long long candidate = currentDistance + weight;
            if (candidate < distance[next]) {
                distance[next] = candidate;
                queue.push({candidate, next});
            }
        }
    }
    return distance;
}
时间 O(log n) · 空间 O(1)

二分边界模板

分别给出满足单调条件的最大位置与最小位置，避免原模板括号缺失和同名函数冲突。

查看 C++ 实现
bool check(int value);

int lastTrue(int left, int right) {
    while (left < right) {
        int middle = left + (right - left + 1) / 2;
        if (check(middle)) left = middle;
        else right = middle - 1;
    }
    return left;
}

int firstTrue(int left, int right) {
    while (left < right) {
        int middle = left + (right - left) / 2;
        if (check(middle)) right = middle;
        else left = middle + 1;
    }
    return left;
}
预处理 O(n) · 单次查询 O(1)

一维前缀和

使用 prefix[i] 表示前 i 个元素之和，区间 [left, right] 的和为两项之差。

查看 C++ 实现
vector<long long> buildPrefix(const vector<int>& values) {
    vector<long long> prefix(values.size() + 1, 0);
    for (size_t i = 0; i < values.size(); ++i) {
        prefix[i + 1] = prefix[i] + values[i];
    }
    return prefix;
}

long long rangeSum(const vector<long long>& prefix, int left, int right) {
    return prefix[right + 1] - prefix[left];
}

02 / Checklist

做题检查清单

Before

先确认约束

数据规模、值域、是否有序、图是否带负权，决定可接受的时间和空间复杂度。

During

写清楚不变量

明确窗口、区间或队列在每一步保持什么性质，避免只凭样例调试。

After

覆盖边界输入

检查空输入、单元素、重复值、极值和无解情况，再评估整数溢出。

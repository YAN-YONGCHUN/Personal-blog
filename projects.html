01 / Computer vision

智能银行卡识别

把一张真实卡面转换为可复核的号码识别结果。

目标
定位卡号区域并识别连续字符
实践重点
预处理、区域定位、字符切分与结果检查
工具
Python · OpenCV · OCR
  1. 读入与校正
  2. 号码区域定位
  3. 字符分割
  4. 识别与复核

当前证据 已公开输入样例与处理链路；演示视频和源码将在隐私处理后补充。

02 / Embedded vision

单目视觉测量装置

2025 年全国大学生电子设计大赛 C 题实践，将检测结果送到嵌入式执行端。

目标
通过单目图像完成目标检测与距离测量
实践重点
视觉定位、几何测量与嵌入式端协同
工具
YOLOv8 · OpenCV · STM32
  1. 相机输入
  2. 目标检测
  3. 几何计算
  4. 结果下发

当前证据 已公开赛题背景与技术链路；实机录像、误差和延迟数据尚待归档。

03 / Embedded control

智能家居控制系统

用 STM32 连接多类元器件，完成环境感知、状态判断与联动输出。

目标
让传感器输入驱动稳定、可解释的设备联动
实践重点
外设驱动、状态逻辑和异常输入处理
工具
STM32 · Sensors · Control
  1. 环境采集
  2. 状态判断
  3. 控制输出
  4. 联动验证

当前证据 已公开系统结构与实践重点；接线图和现场演示仍在整理。

04 / Linux operations

树莓派 Web 服务部署

把多个网页和 Node.js 服务整理成可发布、可回滚、可远程诊断的站点系统。

目标
降低多站点发布和故障恢复的人工成本
实践重点
版本化发布、原子切换、健康检查与失败回滚
工具
Linux · Node.js · Nginx · systemd
  1. 构建校验
  2. 归档上传
  3. 原子切换
  4. 健康检查
  5. 失败回滚

当前证据 本地发布、回滚和安全回归已自动化；真实公网验收需要目标设备连接。

02 / Engineering

项目不止是结果

展示时同步说明输入、处理、输出与验证方式，才能让项目结构被理解和复现。

Input

明确输入质量

记录相机、传感器、光照与数据格式，避免把输入问题误判成算法问题。

Pipeline

拆分处理链路

将采集、预处理、识别、通信和控制分段验证，每段都有可观察结果。

Evidence

用实机证据验收

同时关注准确率、延迟、稳定性和异常恢复，而不是只保留一次成功截图。
